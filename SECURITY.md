# Security policy

`codemode` is currently an early `0.1.x` project. Security fixes are applied to
the latest code on `main`; no older release line is guaranteed to receive
backports yet.

Please report vulnerabilities through GitHub's private security-advisory
feature for this repository when available. If private reporting is not
enabled, open a minimal issue asking the maintainer to establish a private
channel. Do not post exploit details, credentials or private MCP output in a
public issue.

Include the affected commit/version, deployment transport, smallest safe
reproduction and expected impact. See [docs/security.md](docs/security.md) for
the documented trust boundaries and non-goals.
